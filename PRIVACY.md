# Privacy Policy

This document explains how we handle data in this repository, in compliance with GDPR and CCPA regulations.

## Data Collection

### What We Collect
- **GitHub Profile Information**: Public information from GitHub profiles of contributors.
- **Contribution Data**: Commit history, issue comments, and pull request activity.
- **Contact Information**: Email addresses provided voluntarily for communication.

### What We Do NOT Collect
- No API keys, payment credentials, or customer data are stored in code.
- No personal health or financial information.
- No tracking cookies or analytics beyond GitHub's built-in features.

## Data Use

Collected data is used for:
- Managing contributions and collaboration.
- Communicating about project updates.
- Processing payments for sponsored or commissioned work.

## Data Protection

### Security Measures
- GitHub Secret Scanning is enabled.
- Dependabot alerts are monitored and resolved promptly.
- Access control follows the principle of least privilege.
- All collaborators must enable two-factor authentication (2FA).

### Audit & Logging
- Audit logs are enabled for all repositories.
- Logs are reviewed monthly for unauthorized activity.

## Your Rights (GDPR/CCPA)

You have the right to:
- **Access**: Request a copy of your data.
- **Rectification**: Request corrections to inaccurate data.
- **Erasure**: Request deletion of your data (where applicable).
- **Portability**: Receive your data in a portable format.
- **Opt-out**: Opt out of non-essential data processing.

## Data Retention

- Contribution data is retained as part of the repository history.
- Contact information is retained only as long as necessary for communication.
- Payment information is handled by third-party payment processors.

## Third-Party Services

This project may use:
- **GitHub**: For code hosting and collaboration.
- **GitHub Sponsors**: For payment processing.
- Third-party payment gateways for commissioned work.

These services have their own privacy policies.

## Changes to This Policy

We may update this policy from time to time. Significant changes will be announced in the repository.
